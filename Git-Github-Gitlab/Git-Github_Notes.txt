EVERY TIME WE HAVE EDDIT A FILE IN WORKING DIRECTORY 
WE SHOULD USE COMMANDS FOR CODE MOVE IN REMOTE DIRECTORY 

WORKING DIRECTORY ------> THIS IS THE PLACE WHERE THE DEVELOPER CREATES AND MODIFIES CODE.{git add . OR FILE_NAME} ----> GIT ADD COMMAND IS WACTHMAN 
STAGING AREA      ------> ONCE THE CODE IS COMPLETED, IT IS ADDED TO THE STAGING AREA TEMPORARILY AND IS READY TO BE COMMITTED.{git commit -m "change commited"}
LOCAL REPO        ------> ONCE THE CODE IS COMMITTED, IT IS STORED IN THE LOCAL REPOSITORY AND IS READY TO BE PUSHED TO THE REMOTE REPOSITORY HOSTED ON GITHUB.{git push -u origin main} :- -U :- WTACHMAN OR (git push  origin main)
REMOTE REPO       ------> ONCE THE COMMITTED CODE IS PUSHED TO THE REMOTE REPOSITORY, IT IS ON GITHUB AND CAN BE USED FOR DEPLOYMENT TO UAT → STAGING → PROD. (Poush code for testing)

|--git add ----->  |-- git commit       |-- git push
